# Float (`apps/web`)

Consumer console for Markov in this repository. Strategy marketplace, subscribe (tighten-only), live receipts, portfolio kill switch.

```bash
# from repo root
bun run dev
```

Float: http://127.0.0.1:3000  
API: http://127.0.0.1:8787  

Demo owner `owner_demo`. No browser wallet. **Run four-beat demo** or **Run strategy-vault demo**.

Indexer: `apps/indexer`. Vercel config: `vercel.json` in this folder.
